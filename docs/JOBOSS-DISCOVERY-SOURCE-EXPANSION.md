## Findings and implementation boundary

- **Company list first, hiring state separately.** Portfolio membership is a useful relationship/discovery fact, not proof of current hiring, funding date/stage, active operations, a reachable person or permission to send. Verify company domain, current product/fit and available routes from appropriate original sources. Demo/cohort/investment year must not become funding announcement date.
- **Both routes remain required:** check current listed roles when present, and retain suitable no-vacancy companies for honest speculative internship/work inquiries. A directory company need not have a supported ATS to deserve research.
- **Broad discovery, selective ranking:** no recent-batch/size floor that silently removes potentially suitable employers. Mobile/AI first, software secondary; mixed-sector programmes require actual software/product-fit research. Older/larger/unknown-metadata cases remain visible. Source-level missing/paused/capped scope must be honest; never promise zero missed companies.
- **Stable dedup/provenance:** canonical employer identity/domain, source profile/portfolio URL and relationship type, observed timestamps, explicit cohort/date precision and stable IDs. Merge multi-source attribution without overwriting operator exclusions/website/tags or draft/assessment history. Rebrands, lookalikes, acquired entities and member-associated versus invested companies need explicit handling.
- **Gateway/access review before adapters:** public browser retrieval is not permission to automate unrestricted crawling. Verify robots/terms/deny/rate/budgets and actual public pagination/filter behavior per site. No undocumented API exemption, arbitrary vendor-domain trust, alternate raw transport, login bypass or paid service. If no permitted automated path exists, report a manual import/access limitation; don't claim connected coverage.
- **Resumable and measurable:** bounded page/request/company scans, stable scope/cursors, deduplicated company counts and source union; distinguish exact source relationship coverage from final relevant/contactable/drafted cohorts. Dynamic Load More, contradictory empty-state markup and filtered subsets require actual completeness tests; no headline-only scraper.
